使用说明

1. 一键触发
点击"立即开始全网检索"，浏览器将直接调用各数据源的公开 API（PubMed E-utilities、bioRxiv RSS、ClinicalTrials.gov 等），无需服务端中转。
2. 分类浏览
抓取完成后可按 6 大类筛选阅读，每条均可跳转原文；统计卡与分类 Tab 提供快速筛选。
3. 生成日报
点击"生成每日报告"，即可查看图文并茂的结构化报告：含封面、执行摘要、分类分布图、重点文献中文精读（含研究类型、疾病领域、核心发现、行业意义点评、推荐度星级）与分章节详情。
4. 导出归档
报告内一键导出排版精美的 PDF；同时支持 JSON / Markdown 原始数据导出，方便本地存档或二次分析。
⚠️ 由于浏览器跨域限制，部分来源需通过公共 CORS 代理访问；如遇个别来源失败不影响整体结果，可点击"立即开始"重试。PDF 导出依赖 html2pdf.js（CDN 加载），首次使用请保持网络通畅。
